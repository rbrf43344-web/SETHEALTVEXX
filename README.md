# SETHEALTVEX — Optimize Tools (Android)

Cara mendapatkan APK tanpa Android Studio:
1. Buat repo baru di GitHub, unggah seluruh isi folder ini (termasuk folder .github).
2. Buka tab Actions > "Build SETHEALTVEX APK" > Run workflow (atau cukup push ke main).
3. Setelah selesai, unduh artifact "SETHEALTVEX" -> SETHEALTVEX.apk, lalu instal di HP.

Status: kode belum pernah dikompilasi oleh pembuatnya. Jika build gagal, kirim log error Actions untuk diperbaiki.
